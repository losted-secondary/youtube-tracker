# youtube-tracker

## Criador de títulos local

Abra `iniciar_titulos.bat` para usar a interface em http://127.0.0.1:8765.
Cole o resumo de uma história e receba de 5 a 10 sugestões do GPT-6 Astra,
com referências reais da planilha. A chave é lida pelo servidor da configuração
local do `momo-rewrite`, sem copiá-la para o repositório.

Veja [configuração, metodologia e atualização da biblioteca](title_creator/README.md).
